# v2.0.0 验证记录

验证日期：2026-10-08。

## 构建环境

| 环境 | 引擎 | 结果 |
| --- | --- | --- |
| Windows | MiKTeX-XeTeX 4.16（MiKTeX 25.12） | 三版各编译两遍，均为两页 |
| Ubuntu 24.04（WSL） | XeTeX 0.999995，TeX Live 2023/Debian | 三版各编译两遍，均为两页 |

默认使用 TeX Gyre Heros／Cursor 与 Fandol；未启用本地字体覆盖。Windows 验证了可选 Font Awesome 图标，Linux 验证了未安装图标包时的文字回退，两种路径均可编译。

## 内容与文件

- 检查六页布局：没有溢出和缺字；企业版工程实践位于第一页，第二页以开源贡献开始。
- 公开 PDF 来自 Windows 构建；六张预览使用带 CJK 映射数据的 Linux Poppler 从这些 PDF 生成。
- 使用 Poppler 提取中文文本，检查虚构示例标记和示例邮箱；使用 pypdf 检查页数、注释链接、元数据与附件。
- PDF 外部链接仅包含示例域名和示例邮箱。几何占位头像与预览图不包含 EXIF 身份信息。
- 公开源码不包含维护者的真实履历、联系方式、照片、科研成果或电脑路径。
- 发布文件按白名单逐项核对。该检查针对当前发布包，历史提交按既有版本保留。
- 个人简历工作区作为只读排版参考，不纳入本次提交。

## 使用边界

三版两页结论适用于仓库里的虚构样例，不保证用户加入任意长度内容后仍为两页。更换字体可能改变换行，应重新编译并检查。

Overleaf 与其他发行版未单独验证。部分轻量 PDF 工具缺少 Adobe CJK 映射；遇到乱码应先确认工具数据完整，不能仅凭编译返回成功判断预览有效。
